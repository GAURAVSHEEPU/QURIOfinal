# Backend API Documentation (Phase 6)

## 1. Purpose & Architecture

The **Quantum AI Intelligence REST API** is a FastAPI-powered backend service that connects all underlying AI/ML layers (Phase 1–5) into a unified, high-performance REST API interface.

```
 Client (Frontend / Test Suite / Curl)
               │
               ▼
       [ FastAPI Router ] (src/api/main.py)
               │
               ├──► GET  /health                                ──► System Health & Model Readiness
               ├──► GET  /api/learners/{id}/profile             ──► Phase 3 Intelligence Profile
               ├──► GET  /api/learners/{id}/recommendations     ──► Phase 4 Personalized Recommendations
               ├──► POST /api/learners/predict                  ──► Phase 2 ML Model Telemetry Inference
               └──► POST /api/tutor                             ──► Phase 5 Bounded AI Quantum Tutor Loop
```

## 2. Project Directory Structure

```
src/api/
  ├── __init__.py
  ├── main.py                   # FastAPI Application Entrypoint & Middleware Config
  ├── schemas.py                # Pydantic Input/Output Validation Schemas

```

## 5. REST API Endpoints Specification

### A. System Health Diagnostic (`GET /health`)
- **Purpose:** Verifies operational readiness, ML model loading status, and tutor availability.
- **Request Example:** `GET /health`
- **Response Example (200 OK):**
```json
{
  "status": "ok",
  "service": "quantum-learning-platform",
  "models_loaded": true,
  "tutor_available": true
}
```

### D. AI Quantum Tutor Query (`POST /api/tutor`)
- **Purpose:** Executes Phase 5 Generative AI Quantum Tutor & Bounded Loop Engineering workflow.
- **Request Example:** `POST /api/tutor`
```json
{
  "learner_id": "LEARNER_0001",
  "mode": "explain",
  "question": "Why does measurement collapse a quantum state?"
}
```
- **Supported Modes:** `explain`, `hint`, `debug`, `code_explain`, `circuit_explain`, `practice`.
- **Response Example (200 OK):**
```json
{
  "answer": "In quantum mechanics, measurement collapses the superposition wavefunction into a definite eigenstate...",
  "concept": "Quantum Measurement",
  "difficulty": "Intermediate",
  "mode": "explain",
  "hint": "Focus on state vector projection probabilities.",
  "next_step": "Try simulating measurement gates in Qiskit.",
  "confidence": 0.95,
  "quality_score": 90.0,
  "iterations": 1
}
```
- **Error Response (400 Bad Request):**
```json
{
  "detail": "Invalid tutor mode 'invalid_mode'. Supported modes: explain, hint, debug, code_explain, circuit_explain, practice"
}
```
